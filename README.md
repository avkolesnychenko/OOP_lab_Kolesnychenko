# 🍕 Pizza Asteroid App

**PizzaAsteroidApp** — це консольний застосунок мовою C#, що моделює та управляє астрономічною базою даних космічних астероїдів з кулінарними характеристиками піци. Проєкт демонструє фундаментальні принципи ООП (інкапсуляція, розрахункові властивості, перевантажені конструктори та методи), статичні члени класу, перетворення об'єкта в рядок і назад (`ToString` / `Parse` / `TryParse`), зберігання об'єктів у колекції `List<T>`, **серіалізацію та десеріалізацію колекції у файли `*.csv` і `*.json`** (`System.Text.Json`), unit-тестування (MSTest) та обробку винятків.

> Гілка **`lab_7`** — практична робота №7 «Serialization / Deserialization. Saving and loading of objects».

## ✨ Основні можливості

- **Керування місткістю сховища:** перед початком роботи задається ліміт місткості ($N > 0$).
- **Чотири режими додавання об'єктів:** вручну, випадковим конструктором, за замовчуванням, рядком через `TryParse`.
- **Табличний вивід** колекції та значення static-лічильника `CreatedCount`.
- **Пошук:** за бортиком, сиром, назвою (`Find`, `FindIndex`) або діапазоном діаметра (`FindAll`).
- **Поведінка об'єкта:** перевантажений `HeatUp`, `Slice`, `CollideWithTarget`.
- **Static-методи:** `ImpactEnergyFactor`, `Parse`, `TryParse`, `ToString`, `Merge`, `TotalVolume`.
- **Видалення:** за номером (`RemoveAt`) або за назвою, усі збіги (`RemoveAll`).
- **Збереження у файл (пункт 7, Lab-7):**
  - 📄 `1 – зберегти у файл *.csv`;
  - 🧾 `2 – зберегти у файл *.json`;
  - ім'я за замовчуванням `asteroids.csv` / `asteroids.json`, розширення додається автоматично, перед перезаписом існуючого файлу — підтвердження.
- **Зчитування з файлу (пункт 8, Lab-7):**
  - програма показує нумерований список файлів потрібного типу в папці `Data`;
  - файл обирається за номером або іменем;
  - після зчитування виводиться кількість десеріалізованих об'єктів, список пропущених записів із причинами та поточна заповненість.
- **Очищення колекції (пункт 9, Lab-7):** з підтвердженням (`Clear`).

## 📄 Формат CSV

Роздільник — `;`, перший рядок — заголовок, далі рядки у форматі `ToString()`:

```
Name;Crust;DiameterKm;TemperatureCelsius;HasExtraCheese;DiscoveryDate;SauceType
Пепероні-X;Thin;12.5;-40;так;12.04.2021;Барбекю
Гаваї-Ультра;CheeseStuffed;30.5;100;ні;01.01.2020;Томатний Класик
```

| Поле | Допустимі значення |
| :--- | :--- |
| Бортик | `Thin`, `CheeseStuffed`, `DeepDish`, `Classic` (без урахування регістру) або `1`–`4` |
| Діаметр | дійсне число, роздільник — крапка або кома |
| Сир | `так` / `ні`, `1` / `0`, `true` / `false` |
| Дата | `dd.MM.yyyy` |
| Соус | необов'язкове поле; якщо відсутнє — "Томатний Класик" |

## 🧾 Формат JSON

Колекція зберігається цілком як масив; кожен об'єкт містить лише 7 головних властивостей:

```json
[
  {
    "name": "Пепероні-X",
    "crust": "Thin",
    "diameter_km": 12.5,
    "temperature_c": -40,
    "extra_cheese": true,
    "discovery_date": "2021-04-12T00:00:00",
    "sauce": "Барбекю"
  }
]
```

- Кирилиця записується без екранування `\uXXXX` (`JavaScriptEncoder.UnsafeRelaxedJsonEscaping`).
- При зчитуванні регістр імен властивостей не враховується, невідомі властивості ігноруються.
- `crust` приймається і рядком, і числом (`"Classic"` або `4`).
- `EstimatedVolumeKm3`, `CreatedCount` і `ImpactEnergyFactor` у файл не потрапляють.

## 📥 Правила зчитування з файлів

| Ситуація | `*.csv` | `*.json` |
| :--- | :--- | :--- |
| Колекція непорожня | об'єкти додаються в кінець списку | об'єкти додаються в кінець списку |
| Некоректний запис | пропускається тільки цей рядок, решта додається | відхиляється **весь файл**, не додається жоден об'єкт |
| Порожній рядок / `null`-елемент | ігнорується / рахується як пропущений | `null` рахується як пропущений |
| Заголовок | пропускається, якщо є; без заголовка перший рядок — дані | — |
| Досягнуто ліміт N | решта коректних об'єктів → `OverCapacity` | решта коректних об'єктів → `OverCapacity` |
| Файлу немає | `Файл '...' не знайдено.` | `Файл '...' не знайдено.` |

Приклади «битих» рядків CSV, які пропускаються:
- пропущені поля — `Паллада;Thin;5;10`;
- невірні типи — діаметр `abc`, температура `12.5`, сир `може`;
- невідомий бортик — `Square`;
- невірна або неіснуюча дата — `2000-01-01`, `31.02.2021`;
- значення поза межами — діаметр `5000`, назва `@@@`.

## 🛡 Валідація та обмеження

- **Назва:** від 3 до 20 символів; дозволені символи: `[a-zA-Zа-яА-ЯіІїЇєЄґҐ0-9\s\-]`.
- **Діаметр:** від `0.1` до `1000.0` км; крапка або кома як роздільник.
- **Температура:** від `-273°C` до `500°C`.
- **Дата відкриття:** формат `dd.MM.yyyy`, від `01.01.1990` до поточної доби.
- **Соус:** непорожній, без символу `;` (інакше зламався б формат CSV).
- **Ім'я файлу:** порожнє введення → `asteroids.csv` / `asteroids.json`; інше розширення доповнюється потрібним (`backup.txt` → `backup.txt.csv`).
- **Місткість сховища:** $N > 0$; при заповненій колекції пункт 8 не виконує зчитування.
