# 🍕 Pizza Asteroid App

**PizzaAsteroidApp** — це консольний застосунок мовою C#, що моделює та управляє астрономічною базою даних космічних астероїдів з кулінарними характеристиками піци. Проєкт демонструє фундаментальні принципи ООП (інкапсуляція, розрахункові властивості, конструктори з параметрами та за замовчуванням), роботу з переліками (`enum`), захисне програмування з регулярними виразами (`Regex`), консольне форматування та інтерактивне керування станом об'єктів.

## ✨ Основні можливості

- **Керування місткістю сховища:** перед початком роботи задається суворий ліміт місткості ($N > 0$).
- **Три режими додавання об'єктів:**
  - *Ручний режим:* введення кожного поля з перевіркою коректності та повторними спробами при винятках.
  - *Автоматичний режим:* процедурна генерація правдоподібних астероїдів ("Пепероні-X", "Квадро-Формаджо", "Карбонара-99" тощо) з випадковими характеристиками.
  - *За замовчуванням (Default):* миттєва ініціалізація базового шаблону об'єкта через безпараметричний конструктор.
- **Широкоформатний табличний вивід:** наочне відображення реєстру з вирівнюванням колонок (індекс, назва, бортик, тип соусу, діаметр, розрахунковий об'єм, температура, наявність сиру, дата відкриття).
- **Пошук та вибірка:**
  - За стилем тіста / бортика (`CrustType`).
  - За прапорцем подвійного сиру (`HasExtraCheese`).
- **Симуляція фізико-кулінарної поведінки (`PizzaAsteroid`):**
  - 🔥 `HeatUp(int)`: збільшення температури астероїда (обмежено максимумом у 500°C) з фіксацією фази плавлення сиру при $T > 180^\circ\text{C}$.
  - 🍕 `Slice(int)`: поділ астероїда на частини зі зменшенням діаметра ($D_{\text{новий}} = \frac{D}{\sqrt{n}}$).
  - 💥 `CollideWithTarget(string)`: зіткнення з цільовим астрономічним тілом з розрахунком кінетичної енергії удару в мегатонах ТНТ на основі об'єму ($E = V \times 1.75$).
- **Видалення:**
  - За порядковим індексом у таблиці.
  - За назвою (масове видалення всіх збігів без урахування регістру через `StringComparison.OrdinalIgnoreCase`).

### Сутність `PizzaAsteroid`
| Поле / Властивість | Модифікатор | Тип | Опис / Логіка |
| :--- | :--- | :--- | :--- |
| `Name` | `public get / set` | `string` | Назва (3–20 символів, валідація через Regex) |
| `Crust` | `public get / set` | `CrustType` | Тип бортика (перевірка наявності в `Enum`) |

- `Thin (1)` — Тонке хрустке тісто
- `CheeseStuffed (2)` — Бортик із сирним наповненням
- `DeepDish (3)` — Чиказький стиль / товсте пишне тісто
- `Classic (4)` — Класичне традиційне тісто

## 🛡 Валідація та обмеження

Усі дані, що вводяться користувачем вручну, проходять суворий контроль:
- **Назва:** обов'язкове поле від 3 до 20 символів; дозволені символи: `[a-zA-Zа-яА-ЯіІїЇєЄ0-9\s\-]`.
- **Діаметр:** від `0.1` до `1000.0` км. Реалізовано стійкий парсинг незалежно від локалі користувача (крапка або кома як роздільник).
- **Температура:** від `-273°C` (абсолютний нуль) до `500°C`. Захисний метод `ClampTemperature` убезпечує від перевищення 500°C при виклику `HeatUp`.
- **Дата відкриття:** формат `dd.MM.yyyy`, не раніше `01.01.1990` і не пізніше поточної доби.
- **Розрізання (`Slice`):** мінімум на 2 частини.
- **Місткість сховища:** строго $N > 0$.
