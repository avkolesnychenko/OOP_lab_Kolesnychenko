# 🍕 Pizza Asteroid App

**PizzaAsteroidApp** — це консольний застосунок мовою C#, що моделює та управляє астрономічною базою даних космічних астероїдів з кулінарними характеристиками піци. Проєкт демонструє фундаментальні принципи ООП (інкапсуляція, розрахункові властивості, перевантажені конструктори та методи), **статичні члени класу** (static-поля, static-властивості, static-конструктор, static-методи), перетворення об'єкта в рядок і назад (`ToString` / `Parse` / `TryParse`), роботу з переліками (`enum`), захисне програмування з регулярними виразами (`Regex`) та обробку винятків.

> Гілка **`lab_4`** — практична робота №4 «Статичні поля, властивості, методи».

## ✨ Основні можливості

- **Керування місткістю сховища:** перед початком роботи задається ліміт місткості ($N > 0$).
- **Чотири режими додавання об'єктів:**
  - *Ручний режим:* введення кожного поля з перевіркою коректності та повторними спробами при винятках.
  - *Автоматичний режим:* генерація астероїдів ("Пепероні-X", "Квадро-Формаджо", "Карбонара-99" тощо) випадково обраним конструктором.
  - *За замовчуванням:* безпараметричний конструктор з ініціалізатором об'єкта.
  - *Рядком (Lab-4):* введення всього об'єкта одним рядком, який перетворюється через `TryParse`.
- **Табличний вивід** реєстру та значення static-лічильника `CreatedCount`.
- **Пошук:** за типом бортика (`CrustType`) або за прапорцем подвійного сиру (`HasExtraCheese`).
- **Поведінка об'єкта:**
  - 🔥 `HeatUp(int)`, `HeatUp(int, string)`, `HeatUp(double)` — перевантажені версії нагріву (максимум 500°C).
  - 🍕 `Slice(int)` — поділ на частини ($D_{\text{новий}} = \frac{D}{\sqrt{n}}$).
  - 💥 `CollideWithTarget(string)` — енергія удару $E = V \times \text{ImpactEnergyFactor}$.
- **Static-методи (пункт меню 6):**
  - перегляд / зміна `ImpactEnergyFactor` (впливає на всі астероїди одразу);
  - `Parse` з виводом типу і тексту винятку та значення лічильника до/після;
  - `TryParse`;
  - `ToString()` усіх об'єктів з перевіркою сумісності `ToString → Parse → ToString`;
  - `Merge` — злиття двох астероїдів (з можливістю замінити ними вихідні у списку);
  - `TotalVolume` — сумарний об'єм і сумарна енергія удару.
- **Видалення:** за індексом або за назвою (усі збіги, без урахування регістру).

## 🔤 Рядковий формат (ToString / Parse)

```
Назва;Бортик;Діаметр;Температура;Сир;Дата[;Соус]
```

| Поле | Допустимі значення |
| :--- | :--- |
| Бортик | `Thin`, `CheeseStuffed`, `DeepDish`, `Classic` (без урахування регістру) або `1`–`4` |
| Діаметр | дійсне число, роздільник — крапка або кома |
| Сир | `так` / `ні`, `1` / `0`, `true` / `false` |
| Дата | `dd.MM.yyyy` |
| Соус | необов'язкове поле; якщо відсутнє — "Томатний Класик" |

Приклад: `Пепероні-X;Thin;12.5;-40;так;12.04.2021;Барбекю`

Винятки `Parse`:
- `ArgumentNullException` — рядок `null`;
- `FormatException` — порожній рядок, неправильна кількість полів, нечислові значення, невідомий бортик, неправильні «сир» чи дата;
- `ArgumentException` / `ArgumentOutOfRangeException` — формат правильний, але значення порушує правила предметної області.

## 🛡 Валідація та обмеження

- **Назва:** від 3 до 20 символів; дозволені символи: `[a-zA-Zа-яА-ЯіІїЇєЄґҐ0-9\s\-]`.
- **Діаметр:** від `0.1` до `1000.0` км; крапка або кома як роздільник.
- **Температура:** від `-273°C` до `500°C`; `ClampTemperature` обмежує нагрів до 500°C.
- **Дата відкриття:** формат `dd.MM.yyyy`, від `01.01.1990` до поточної доби.
- **Соус:** непорожній, без символу `;`.
- **`ImpactEnergyFactor`:** від `0.1` до `100.0`.
- **`Slice`:** мінімум 2 частини. **`Merge`:** не можна зливати астероїд сам із собою.
- **Місткість сховища:** $N > 0$.
